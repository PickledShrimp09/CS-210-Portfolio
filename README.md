## About This Repository

This repository serves as my portfolio for CS 210 at Southern New Hampshire University. It contains my Corner Grocer project, which demonstrates my understanding of C++ programming, object-oriented design, file handling, and data organization.

## Project Reflection

### Project Summary

For this project, I created a C++ program that tracks how frequently different grocery items are purchased. The purpose of the program was to help Corner Grocer better understand customer purchasing habits so that the store could make informed decisions about how to organize its products. The program allows users to search for individual items, view a complete list of purchase frequencies, and display the results as a histogram. It also automatically creates a backup file containing the purchase information.

### What I Did Well

I think a part of the project I did well was how I organized the program. I used a GroceryTracker class to separate the program's functionality and a map to store the grocery items with their purchase rates. This made the information easier to organize and retrieve. I also included input validation to prevent users from engaging with invalid inputs. During testing, I was able to verify that the different menu options worked correctly and displayed the expected information.

### Areas for Improvement

One area I could improve is how the program handles its input files. Currently, the program depends on a specific file being available. I could expand feedback to give clearer messages when a file is missing or cannot be opened. I could also improve the user interface by making the menu and results easier to navigate. These changes would make the program easier to use

### Challenges and Resources

One of the more challenging parts of the project was organizing the purchase information and displaying it in different formats. I needed to make sure the program could count each item correctly and use that information for both the frequency list and histogram. Breaking the program into smaller functions helped me approach these problems individually. 

### Transferable Skills

Good skills that I used through this project were working with classes, organizing data, handling files, and validating user input. These are skills that can be applied to a wide range of programming languages and projects. I also gained more experience testing a program to make sure it works as intended. Understanding how to organize a program into smaller components makes them easier to work with, which helps when working with larger scale projects.

### Maintainability, Readability, and Adaptability

I tried to make the program maintainable by separating its different responsibilities into functions and using a GroceryTracker class to manage the purchase information. This makes the code easier to understand because each part of the program has a specific purpose. I also gave the project simple yet effective descriptors to help explain how the code works. By keeping the program organized, it should be easier to make changes or add functionality without having to rewrite the entire program.
